# 节点桌面端到端验收

第5步在隔离测试链与实际桌面候选上执行。使用公开测试账户和证书，禁止真实链交易；缺少条件应报告未执行。

覆盖应用启动/节点启动停止和数据库释放、九个导航入口、只读机构与提案查询、冷签取消/过期/拒绝/成功、热签失败与重试、普通/紧急换钥重启及回滚、TLS证书拒绝与恢复、清算重启与幂等；决议发行和销毁按钮继续按现状禁用。验收核对创世哈希与状态根、IPC字段、UI截图及交互顺序。性能预算由固定环境明确交付，不能以功能测试次数代替吞吐/延迟。

钱包管理：红蓝圆点保持13×13px，红点不删除热钱包；蓝点叉→横线→删除，失败保留记录并可重试，提交期间不重复删除。圆点及名称左侧空白不选择钱包，名称、地址、金额区域仍可选择。名称按当前最长记录共用固定列宽并左对齐，细竖线右侧地址左对齐，金额右对齐；完整地址、大金额、历史长名称、空列表、长列表及窄窗口均保持添加区与列表等宽、共同滚动。新增名称最多10个Unicode字符，检查中文组合输入和非BMP字符，已有长名称不截断。
